# SideStore로 설치하기 — 케이블 없이 쓰는 방법

SideStore는 아이폰 안에서 돌아가는 앱 설치 도구입니다.
**처음 한 번만 PC로 설정**해 두면, 그 뒤로는 아이폰이 Wi-Fi로 알아서 서명을 갱신합니다.
매주 케이블 꽂고 재설치하는 일이 없어집니다.

여기에 더해 **내 앱 저장소를 SideStore에 등록**해 두었습니다.
앞으로 앱을 고치면 SideStore 안에 업데이트 버튼이 뜨고, 눌러서 바로 받으면 됩니다.

```
[처음 한 번만]  PC ──▶ 아이폰에 SideStore 설치
[그 다음부터]   아이폰 안에서 전부 해결 (설치 · 업데이트 · 7일 갱신)
```

---

## 솔직하게 먼저 알아둘 점

- **7일 제한 자체는 사라지지 않습니다.** 무료 Apple ID의 규칙이라 SideStore도 못 바꿉니다.
  다만 사람이 케이블을 꽂는 대신 **아이폰이 알아서 갱신**해 줍니다. 체감상 신경 쓸 일이 없어집니다.
- **일주일에 한 번 이상은 앱을 켜 두세요.** 갱신은 아이폰이 인터넷에 연결돼 있을 때 일어납니다.
  2주쯤 완전히 방치하면 만료돼서 SideStore로 다시 설치해야 합니다(기록은 유지됩니다).
- **무료 Apple ID는 앱 3개까지**입니다. SideStore가 1개를 쓰니 여유는 2개입니다.
- SideStore 자체 설치 절차는 버전에 따라 자주 바뀝니다. 아래 순서가 안 맞으면
  **공식 안내 <https://sidestore.io> 를 기준**으로 하세요. 큰 흐름은 같습니다.

---

## 1단계. 아이폰에 SideStore 설치하기 (처음 한 번만)

### 준비물

- 이미 깔아 둔 **Sideloadly** 와 **iTunes**(애플 공식 사이트 버전)
- USB 케이블 (이번 한 번만 씁니다)
- 본인 Apple ID

### 순서

1. <https://sidestore.io> 에서 **SideStore.ipa** 를 내려받습니다.
2. **페어링 파일**을 만듭니다. SideStore 사이트가 안내하는 도구(윈도우용 `jitterbugpair` 등)를
   실행하면 `.mobiledevicepairing` 파일이 하나 나옵니다.
   아이폰을 USB로 연결한 상태에서 실행해야 합니다.
3. **Sideloadly로 SideStore.ipa 를 아이폰에 설치**합니다.
   (`WoholEnglish.ipa` 를 설치했던 것과 똑같은 방법입니다)
4. 아이폰 **설정 → 일반 → VPN 및 기기 관리 → 본인 Apple ID → 신뢰**
5. 아이폰 App Store에서 **StosVPN** 을 설치하고 실행해 연결합니다.
   SideStore가 아이폰 내부와 통신하는 데 쓰는 통로라서 꼭 필요합니다.
6. 2번에서 만든 페어링 파일을 아이폰으로 옮겨(에어드롭·카톡 나에게 보내기·파일 앱 아무거나)
   **SideStore를 열고 불러오기** 합니다.
7. SideStore에서 **Apple ID로 로그인**합니다. 2단계 인증을 쓰면 앱 암호가 필요할 수 있습니다
   (<https://account.apple.com> → 로그인 및 보안 → 앱 암호).

여기까지 하면 케이블은 이제 필요 없습니다.

## 2단계. 내 앱 저장소 등록하기

SideStore에서 **Sources(소스) 탭 → 오른쪽 위 `+`** 를 누르고 아래 주소를 붙여 넣으세요.

```
https://raw.githubusercontent.com/yunseok-map/english/main/source/apps.json
```

> 아이폰에서 이 문서를 보고 있다면 주소를 길게 눌러 복사하면 편합니다.

등록하면 **"yunseok 앱 저장소"** 가 생기고 그 안에 **워홀 영어 훈련**이 보입니다.
**GET / 설치** 를 누르면 끝입니다. PC도 케이블도 필요 없습니다.

### 이미 Sideloadly로 설치해 둔 게 있다면

**먼저 홈 화면에서 지우고** SideStore로 다시 설치하세요.
Sideloadly로 넣은 앱은 SideStore가 갱신해 주지 못해서, 그대로 두면 7일 뒤 또 만료됩니다.
지웠다가 SideStore로 다시 깔면 그때부터는 자동 갱신 대상이 됩니다.

> 학습 기록은 앱을 지우면 함께 지워집니다.
> 이미 공부한 기록이 있다면 앱에서 **설정 → 내보내기** 로 백업 파일을 저장해 두었다가,
> 새로 설치한 뒤 **가져오기** 로 되돌리세요.

---

## 3단계. 앞으로 업데이트하는 법

제가(또는 본인이) 앱을 고치고 새 태그를 올리면 자동으로 새 버전이 만들어집니다.

```bash
git add -A
git commit -m "수정 내용"
git push
git tag v1.0.3
git push origin v1.0.3
```

10분쯤 뒤 아이폰에서 **SideStore → My Apps** 를 열면 **업데이트** 버튼이 떠 있습니다.
누르면 끝입니다.

## 잘 안 될 때

| 증상 | 해결 |
| --- | --- |
| SideStore가 "Could not connect" / 갱신 실패 | **StosVPN이 연결돼 있는지** 확인하세요. 꺼져 있으면 SideStore가 아무것도 못 합니다. |
| 저장소를 추가했는데 앱이 안 보임 | 저장소 화면을 아래로 당겨 새로고침하세요. GitHub 주소는 몇 분간 캐시될 수 있습니다. |
| "설치할 수 없음" / 앱 3개 제한 | 무료 계정은 앱 3개까지입니다. 안 쓰는 사이드로드 앱을 지우세요. |
| 앱이 갑자기 안 열림 | 서명이 만료된 겁니다. SideStore를 열어 새로고침(Refresh)하면 다시 열립니다. |
| SideStore 자체가 안 열림 | SideStore도 7일 서명 대상입니다. Sideloadly로 SideStore를 한 번 더 설치하면 됩니다. |
| 페어링 파일 만들기가 막힘 | 아이폰을 연결한 뒤 **"이 컴퓨터를 신뢰"** 를 눌렀는지, iTunes가 기기를 인식하는지 확인하세요. |
