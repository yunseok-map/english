# SideStore로 설치하기 — 케이블 없이 쓰는 방법

SideStore는 아이폰 안에서 돌아가는 앱 설치 도구입니다.
**처음 한 번만 PC로 설정**해 두면, 그 뒤로는 아이폰이 Wi-Fi로 알아서 서명을 갱신합니다.
매주 케이블 꽂고 재설치하는 일이 없어집니다.

여기에 더해 **내 앱 저장소를 SideStore에 등록**해 두었습니다.
앞으로 앱을 고치면 SideStore 안에 업데이트 버튼이 뜨고, 눌러서 바로 받으면 됩니다.

```
[처음 한 번만]  PC ──▶ iloader 로 아이폰에 SideStore 설치
[그 다음부터]   아이폰 안에서 전부 해결 (설치 · 업데이트 · 7일 갱신)
```

> 2026-08 기준 공식 문서(<https://docs.sidestore.io>)를 따라 정리했습니다.
> 절차가 자주 바뀌므로 안 맞으면 공식 문서를 우선하세요.

---

## 솔직하게 먼저 알아둘 점

- **7일 제한 자체는 사라지지 않습니다.** 무료 Apple 계정의 규칙이라 SideStore도 못 바꿉니다.
  다만 사람이 케이블을 꽂는 대신 **아이폰이 알아서 갱신**해 줍니다. 체감상 신경 쓸 일이 없어집니다.
- **일주일에 한 번 이상은 앱을 켜 두세요.** 갱신은 아이폰이 Wi-Fi에 연결돼 있고
  LocalDevVPN이 켜져 있을 때 일어납니다. 2주쯤 방치하면 만료돼서 다시 설치해야 합니다.
- **무료 Apple 계정은 앱 3개까지**입니다. SideStore가 1개를 쓰니 여유는 2개입니다.
- **아이폰에 암호(passcode)가 설정돼 있어야 합니다.** 안 걸려 있으면 설치가 진행되지 않습니다.
- **모바일 데이터는 안 됩니다.** Wi-Fi에서 하세요.

---

## 0단계. 준비물

| 항목 | 내용 |
| --- | --- |
| 아이폰 | iOS 15.0 이상, 암호 설정됨 |
| PC | 64비트 Windows 8 이상 (32비트·Windows 10 ARM 불가) |
| iTunes | <https://www.apple.com/itunes/download/win64> 의 애플 공식 버전 권장 (Microsoft Store 버전도 가능). **iloader보다 먼저 설치** |
| iloader | <https://github.com/nab138/iloader/releases> → `iloader-windows-x64.msi` (자산 목록이 접혀 있으면 "Show all assets" 클릭) |
| 케이블 | 이번 한 번만 씁니다 |

> **Sideloadly는 이제 필요 없습니다.** 예전에는 SideStore.ipa를 Sideloadly로 넣고
> jitterbugpair로 페어링 파일을 직접 만들어야 했지만, 지금은 iloader가 두 가지를 다 처리합니다.

---

## 1단계. PC에서 SideStore 설치 (처음 한 번만)

1. **iTunes 먼저 설치**합니다. (iloader가 애플 드라이버를 씁니다)
2. `iloader-windows-x64.msi` 를 받아 설치합니다. 계속 "다음"만 누르면 됩니다.
3. 아이폰을 **USB로 연결**하고, 아이폰에 뜨는 **"이 컴퓨터를 신뢰"** 를 누릅니다.
   (아이폰 화면 잠금은 풀어 두세요)
4. **iloader 실행** → **Apple 계정으로 로그인**합니다.
   - 이메일 주소의 **대소문자까지 정확히** 입력해야 합니다.
   - 2단계 인증을 쓰면 앱 암호가 필요할 수 있습니다
     (<https://account.apple.com> → 로그인 및 보안 → 앱 암호).
5. 목록에서 **내 기기를 선택**합니다.
6. **"Install SideStore (Stable)"** 를 누릅니다.

여기서 케이블 역할은 끝입니다.

---

## 2단계. 아이폰에서 마무리

1. **설정 → 일반 → VPN 및 기기 관리**
   → "개발자 앱" 아래 **본인 Apple 계정 이름** 선택 → **신뢰**
2. **개발자 모드 켜기** (iOS 16 이상)
   **설정 → 개인정보 보호 및 보안** → 맨 아래 **개발자 모드** 켜기 → 재시동
   - iOS 18 이상에서는 **"허용 후 재시동"** 이 뜨고 암호를 물어봅니다.
3. App Store에서 **LocalDevVPN** 을 설치하고 열어 **Connect**.
   - "VPN 구성 허용" 이 뜨면 **허용** + 암호 입력.
   - **이 VPN은 SideStore로 설치·업데이트·갱신할 때마다 켜져 있어야 합니다.**
     (예전 이름이 StosVPN 이었습니다)
4. **SideStore 를 열고**, iloader에서 쓴 것과 **같은 Apple 계정으로 로그인**합니다.
5. **My Apps** 에서 SideStore 옆의 **"7 DAYS"** 를 눌러 한 번 수동 새로고침합니다.
   인증서 생성/폐기 확인이 뜨면 승인하세요.

---

## 3단계. 내 앱 저장소 등록하기

SideStore에서 **Sources(소스) 탭 → 오른쪽 위 `+`** 를 누르고 아래 주소를 붙여 넣으세요.

```
https://raw.githubusercontent.com/yunseok-map/english/main/source/apps.json
```

> 아이폰에서 이 문서를 보고 있다면 주소를 길게 눌러 복사하면 편합니다.

등록하면 **"yunseok 앱 저장소"** 가 생기고 그 안에 **워홀 영어 훈련**이 보입니다.
**GET / 설치** 를 누르면 끝입니다. PC도 케이블도 필요 없습니다.

### 이미 Sideloadly로 설치해 둔 게 있다면

**먼저 홈 화면에서 지우고** SideStore로 다시 설치하세요.
Sideloadly로 넣은 앱은 SideStore가 갱신해 주지 못해서, 그대로 두면 7일 뒤 또 만료됩니다.
지웠다가 SideStore로 다시 깔면 그때부터는 자동 갱신 대상이 됩니다.

> 학습 기록은 앱을 지우면 함께 지워집니다.
> 이미 공부한 기록이 있다면 앱에서 **설정 → 내보내기** 로 백업 파일을 저장해 두었다가,
> 새로 설치한 뒤 **가져오기** 로 되돌리세요.

---

## 4단계. 앞으로 업데이트하는 법

앱을 고치고 새 태그를 올리면 GitHub Actions가 알아서 IPA를 만들고 저장소를 갱신합니다.

```bash
git add -A
git commit -m "수정 내용"
git push
git tag v1.0.4
git push origin v1.0.4
```

10분쯤 뒤 아이폰에서 **SideStore → My Apps** 를 열면 **업데이트** 버튼이 떠 있습니다.
누르면 끝입니다.

## 잘 안 될 때

| 증상 | 해결 |
| --- | --- |
| SideStore가 "Could not connect" / 갱신 실패 | **LocalDevVPN이 연결돼 있는지** 확인하세요. 꺼져 있으면 SideStore가 아무것도 못 합니다. |
| iloader가 기기를 못 찾음 | iTunes가 설치돼 있는지, 아이폰 잠금이 풀려 있는지, **"이 컴퓨터를 신뢰"** 를 눌렀는지 확인하세요. |
| 로그인 실패 | 이메일 **대소문자**를 확인하고, 2단계 인증 계정이면 **앱 암호**를 쓰세요. |
| 설치는 됐는데 앱이 안 열림 | 설정 → 일반 → VPN 및 기기 관리에서 **신뢰**를 눌렀는지, **개발자 모드**가 켜져 있는지 확인하세요. |
| 저장소를 추가했는데 앱이 안 보임 | 저장소 화면을 아래로 당겨 새로고침하세요. GitHub 주소는 몇 분간 캐시될 수 있습니다. |
| "설치할 수 없음" / 앱 3개 제한 | 무료 계정은 앱 3개까지입니다. 안 쓰는 사이드로드 앱을 지우세요. |
| 앱이 갑자기 안 열림 | 서명이 만료된 겁니다. LocalDevVPN을 켜고 SideStore에서 새로고침(Refresh)하면 다시 열립니다. |
| SideStore 자체가 안 열림 | SideStore도 7일 서명 대상입니다. iloader로 한 번 더 설치하면 됩니다. |
