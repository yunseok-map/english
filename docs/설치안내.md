# 아이폰에 직접 설치해서 앱처럼 쓰기

App Store에 올리지 않고 내 아이폰에서만 앱처럼 쓰는 방법을 정리했습니다.
**맥이 없어도 되는 방법(1·2번)** 을 먼저 읽어보세요.

---

## 방법 1. 무료 정적 호스팅 + 홈 화면에 추가 (가장 추천)

PC를 켜 두지 않아도 되고, 오프라인에서도 열립니다. 비용 없음.

### 1) 빌드

```bash
pnpm install
pnpm build
```

`dist/public` 폴더가 완성된 앱입니다. 이 폴더 하나만 올리면 됩니다.

### 2) 정적 호스팅에 올리기

아래 중 아무거나 하나면 됩니다. 셋 다 무료이고 HTTPS를 자동으로 붙여 줍니다.

| 서비스 | 방법 |
| --- | --- |
| **Netlify Drop** | <https://app.netlify.com/drop> 에 `dist/public` 폴더를 드래그 앤 드롭. 계정 없이도 바로 주소가 나옵니다. |
| **Cloudflare Pages** | 대시보드 → Workers & Pages → Create → Pages → Upload assets 에서 `dist/public` 업로드 |
| **Vercel** | `npx vercel deploy dist/public --prod` |

> HTTPS 주소여야 오프라인 캐시(서비스워커)가 켜집니다. 위 서비스들은 기본이 HTTPS입니다.

### 3) 아이폰에서 홈 화면에 추가

1. **사파리**로 위에서 받은 주소를 엽니다. (크롬 말고 반드시 사파리)
2. 화면 아래 **공유 버튼**(□↑) 을 누릅니다.
3. 목록을 내려 **"홈 화면에 추가"** 를 누릅니다.
4. 이름을 확인하고 **추가**.

홈 화면에 아이콘이 생기고, 그 아이콘으로 열면 사파리 주소창 없이 **전체 화면 앱처럼** 실행됩니다.
학습 기록은 아이폰 안에 저장되고, 비행기 모드에서도 동작합니다.

---

## 방법 2. 내 PC에서 잠깐 열어보기 (같은 Wi-Fi)

설치 없이 화면만 빨리 확인하고 싶을 때 씁니다.

```bash
pnpm build
pnpm serve:lan
```

터미널에 `http://192.168.x.x:4173/` 같은 주소가 표시됩니다.
아이폰을 **같은 Wi-Fi**에 연결하고 사파리에서 그 주소를 여세요.

- 홈 화면에 추가도 됩니다.
- 다만 HTTP 접속이라 **오프라인 캐시는 동작하지 않습니다.** PC를 끄면 열 수 없어요.
- 계속 쓸 거라면 방법 1로 옮기는 걸 권합니다.

---

## 방법 3. Xcode로 진짜 네이티브 앱 설치 (맥 필요)

맥이 있다면 네이티브 앱으로 설치할 수 있습니다. 마이크·음성 인식 등 네이티브 기능이 필요할 때 유리합니다.

```bash
pnpm ios:sync
pnpm ios:open
```

Xcode에서:

1. **Signing & Capabilities** → Team 에 본인 Apple ID 선택 (무료 계정 가능)
2. **Bundle Identifier** 를 본인만의 값으로 변경 (예: `com.yunseok.woholenglish`)
3. 아이폰을 케이블로 연결하고 상단에서 기기 선택 → **Run**
4. 아이폰에서 *설정 → 일반 → VPN 및 기기 관리* 에서 본인 개발자 인증서를 **신뢰**

> 무료 Apple 계정으로 설치하면 **7일마다 만료**되어 다시 설치해야 합니다.
> 유료 개발자 계정($99/년)이면 1년간 유지됩니다.

## 자주 묻는 것

**학습 기록은 어디에 저장되나요?**
아이폰 브라우저 저장소(IndexedDB)에 저장됩니다. 서버로 전송되지 않습니다.
설정 → *내보내기* 로 JSON 백업을 만들어 두면 기기를 바꿔도 복원할 수 있습니다.

**앱을 지우면 기록이 사라지나요?**
홈 화면 아이콘을 지우면 저장소도 함께 지워질 수 있습니다. 중요한 기록은 미리 내보내기 하세요.

**업데이트는 어떻게 하나요?**
방법 1이면 다시 빌드해서 같은 곳에 올리면 됩니다. 앱을 열면 자동으로 새 버전이 적용됩니다.

**AI 대화 기능을 쓰려면?**
설정 → *AI 대화 모델* 에서 Gemini/OpenAI/Claude/OpenRouter 중 하나를 고르고 API 키를 넣으세요.
키 없이도 내장 코칭으로 대화 연습은 가능합니다. 키는 이 기기에만 저장됩니다.
